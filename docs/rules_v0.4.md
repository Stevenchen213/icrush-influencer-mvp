# ICRUSH 达人筛选规则 v0.5

> 版本：v0.5
> 最后更新：2026-06-10
> 适用范围：ICRUSH 国内办公室德语区（DE + AT）首饰 / 时尚类品牌合作达人调研

---

## 一、硬性条件

### 1. 地区确认：德国 / 奥地利

**判断标准（按优先级）：**

| 优先级 | 信号 | 来源 | 判定方法 |
|--------|------|------|---------|
| **①（最高）** | Wednesday 受众国家+城市分布 | Upfluence API（免费，Wednesday 会员） | 受众国家 #1 = DE **且占比 >35%**，**且** 受众城市 #1 为德国/奥地利城市 → **直接确认地区**，跳过语言检测 |
| ②（fallback） | 近 20 条帖子 25% 为德语 caption | Apify Profile Scraper（TT 用 `textLanguage` 字段，IG 用启发式） | de / (de + en) ≥ 25% |
| ③（fallback） | 近 20 条视频评论区 60% 以上德语，**每条视频抓 10 条文字评论**，**表情类评论不计入** | Apify Comments Scraper（TT 用 `language`，IG 用启发式） | de / (de + en) ≥ 60% |

**组合规则：**

- **Wednesday 有数据 → 完全采信**，跳过 ② 和 ③（最省钱）
- **Wednesday 无数据 → fallback 原流程**：
  - ② 和 ③ **必须同时满足**
  - IG 优先读 `about.country` 字段（需 `includeAboutSection:true`），TT 用 bio 城市名作为辅助参考
  - 若 bio/账号在 DE/AT + caption ≥ 25% → **直接标记合适**，不调评论 API
  - 若 bio/账号在 DE/AT + caption < 25% → **调评论 API 检测 ③**
  - 若 bio 无地区 + caption ≥ 25% → 凭语言信号通过
  - 若 bio 无地区 + caption < 25% → **不合适**（不浪费评论 API）

### 2. 粉丝数量

| 平台 | 合适区间 | <10K | <1K |
|------|---------|------|-----|
| TikTok | 10K - 500K | 备注为**置换组** | **直接 PASS** |
| Instagram | 10K - 300K | 备注为**置换组** | **直接 PASS** |

---

### 3. 帖子总数

- **TikTok 达人**：发帖总数 > 200 标记为合适
- **Instagram 达人**：发帖总数 > 200 标记为合适
  - **例外**：`postsCount` 不含"未同步到主页网格"的 reels，纯 reel 型账号会被低估
  - 150–199 帖且 `latestPosts` 中 reels（Video 类型）占比 ≥ 50% → 豁免帖数淘汰，放行 STAGE 2
  - 帖数 < 150 → 直接 PASS
- **私密账户直接 PASS**

---

### 4. 近三月视频平均浏览量

| 区间 | 判定 |
|------|------|
| ≥ 10,000 | 可估算 |
| 4,000 - 9,999 | 合适 |
| 2,000 - 3,999 | 备注为**置换组** |
| < 2,000 | **PASS** |

**省钱注明：** 由于此判断需调用 Apify 且较烧钱，**仅当 1 / 2 / 3 都符合时才判断 4**；前面有不符合的直接 PASS，无需后续检测。

---

### 5. 职业

若达人职业**官方认证**为**艺术家 / 律师** → **直接 PASS**。

判断信号（任一命中即视为该职业）：

| 职业 | IG `businessCategoryName` | bio 关键词（德语 / 英语）|
|------|-------------------------|--------------------------|
| Lawyer | 含 `Lawyer & Law Firm` | `Notarin`, `Anwältin`, `Notar`, `Anwalt`, `Kanzlei`, `Rechtsanwalt`, `Rechtsanwältin`, `Advokat`, `Lawyer`, `Attorney` |
| Artist | 含 `Artist`、`Visual Artist`、`Performance Art` 等 | `Künstler`, `Künstlerin`, `Maler`, `Malerin`, `Bildhauer`, `Skulptur`, `Schauspielerin`, `Schauspieler` |

---

### 6. 粉丝占比

- **男粉丝占比 > 50%** → 标记为不合适
- **例外**：若粉丝数量 > 100K，允许男粉占比最高 **65%**
- 数据来源：Wednesday/Upfluence API（`gender_image_extractor`）；若无 Wednesday 数据则显示"无信息"

（输出表中显示**女粉占比**，方便阅读；判定逻辑用男粉占比做阈值判断）

## 三、最终输出项（一期目标）

1. 平台：Tiktok / Ins
2. 用户名
3. 粉丝数量
4. 帖数
5. 地区是否准确：是 / 否 / -（"-" 表示 bio 无地区显示）

## 四、判定顺序（短路评估，省钱用）

为了避免无谓的 Apify 调用，按这个顺序判定：

1. **职业** → 是艺术家 / 律师 → PASS
2. **私密** → PASS
3. **帖数** < 200 → PASS（IG 150-199 reel-heavy 豁免）
4. **粉丝** < 1K 或超出范围 → PASS
5. **Wednesday 查询**（免费）→ 有数据：受众国家/城市 + 性别判定 → 地区&性别通过则 ✅；任一项不通过则 ❌
6. **地区 + 语言**（仅 Wednesday 无数据者）→ 若 bio/账号 是 DE / AT + caption < 25% 德语 → 调评论 API；其他情况按上面省钱方案
7. **近 3 月平均浏览** < 2,000 → PASS
8. 综合判定置换组 / 是

## 五、已知问题（v0.4 修复）

- **TT 语言占比 bug**（v0.3 → v0.4）：旧版用 `de / total`，会把表情包视频（textLanguage = "un"）算进分母，导致德国达人的德语比例被严重低估（例如 @sarah.salii 实际 47%，旧公式算 30%）。**v0.4 改为 `de / (de + en)`，与 IG 算法一致**。
