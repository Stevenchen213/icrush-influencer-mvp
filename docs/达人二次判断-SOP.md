# 达人二次判断 — 操作 SOP

## 表格用途

Pipeline 自动筛选后，将需要人工判断的结果同步到此表（排除「❌ 否」和「🟡 已入库」），供团队成员做最终审核。

---

## 字段说明

### 代码自动输出的字段（**禁止修改**）

| 字段 | 含义 | 说明 |
|------|------|------|
| 用户名 | IG/TT 用户名 | - |
| 平台 | IG 或 TT | - |
| 达人链接 | 个人主页 URL | - |
| 粉丝数量 | 粉丝数 | Apify 抓取，偶尔为 0 或异常 |
| 帖数 | 总帖子数 | Apify 抓取 |
| 近三月平均浏览量 | 近 90 天 Reel/Video 平均播放 | Apify 抓取；无 Reel 则显示 `-` |
| 女粉占比 | 女性粉丝 % | Wednesday/Upfluence 数据，无数据则显示「无信息」 |
| 地区准确性 | 德国/奥地利地区判断 | 「是」= Wednesday 受众数据证实；「是 (语言)」= 无 Wednesday 数据，由 caption 语言推断；「待复查」= 两者均无数据 |
| Caption德语占比 | 帖子 caption 中德语比例 | 仅统计 5 字符以上的 caption；无 Wednesday 数据时此字段权重更高 |
| 近3月商单 | 近 90 天商业合作帖统计 | 格式：`品类×N`，如「美妆×3, 服饰×1」 |
| 判定结果 | 代码自动判定 | 见下方判定逻辑 |
| 原因 | 判定依据 | 例如「粉丝 300<1K」「bio 无地区 + 语言 10%<25%」 |
| 批次ID | 跑批标识 | `日期_batchN_M` |
| 日期 | 跑批日期 | - |

### 人工填写的字段（**仅这两列可编辑**）

| 字段 | 含义 | 选项 |
|------|------|------|
| **总结反馈** | 对代码判定结果的评价 | 自由文本 |
| **二次判定** | 人工最终判断 | `很好` / `一般` / `淘汰` |

---

### 字段核对说明

| 字段 | 核对要求 |
|------|----------|
| 近3月商单 | **仅供参考**，不用仔细核对。若明显不符（如明明有大量商单却显示「无」）可在总结反馈中反馈 |
| 其他所有列 | **需要核对**，如粉丝数、帖数、浏览量、地区、caption 德语占比等，发现明显偏差请在总结反馈中反馈 |

---

## 判定结果逻辑说明

### ✅ 是
通过全部自动化检查：
- 粉丝 1K–300K（IG）/ 1K–500K（TT）
- 帖数 ≥ 200（或 IG 帖数≥150 且 Reel 占比≥50%）
- 地区确认为德国/奥地利（Wednesday 受众 DE+AT≥35%，或 caption 德语≥25%）
- 女粉占比达标（≤100K粉：男粉≤50%；>100K粉：男粉≤65%）
- 近 3 月平均浏览量 ≥ 4000
- 非品牌号、非男性博主
- 近 3 月有商单

### 🟡 复查
自动判定通过但有疑点，需人工确认：
- **地区存疑**：bio 写了德国城市，但 caption 德语占比 < 25%（可能是发英文内容的德国博主）
- **无商单**：所有技术条件通过，但近 3 月未检测到商业合作（可能是新账号、或者商单标记不明显的博主）
- **Wednesday 挂了**：本轮 Wednesday API 登录失败，无法获取受众数据

> **建议操作**：点进主页看内容语言和风格，判断是否真的适合德国市场。

### 🟡 置换组
条件基本合格但规模/互动偏低，适合**置换/低费合作**（送产品换推广）：
- 粉丝 1K–10K（微型达人），或
- 近 3 月平均浏览量 2,000–4,000

> **建议操作**：粉丝少但内容质量好的可以联系置换；浏览量偏低的谨慎。

### 🟡 人工复查
- IG 账号近 3 月**没有任何 Reel 或 Video**（可能是纯图文号），无法计算浏览量
- 周三无数据且 bio 无地区信息

> **建议操作**：点进主页看是否值得破例（比如内容特别优质的图文号）。

## Wednesday 数据说明

**「女粉占比」和「地区准确性」为何显示「无信息」？有两种可能：**

| 原因 | 表现 | 影响 |
|------|------|------|
| 达人未被 Wednesday/Upfluence 收录 | 该达人每次跑都是无信息 | 代码回退到用 caption 语言判断地区。如果「Caption德语占比」也低，会被标为「❌ 否」或「🟡 复查」 |
| Wednesday 当月额度用完 | 整个批次全部显示无信息 | 该批次大量被标「🟡 复查」，需人工多看 |

> **审核时**：如果单个达人无 Wednesday 数据但 caption 德语占比高、内容明显是德国的 → 可能是未收录，不代表不合适。

## 语言判断逻辑

| Wednesday 有数据 | Wednesday 无数据 |
|------|------|
| 用受众 DE+AT 占比 + 城市判断地区 | 用 caption 德语占比 + bio 城市判断地区 |
| 女粉占比有具体数值 | 女粉占比显示「无信息」 |
| 地区准确性较可靠 | 地区准确性别依赖 caption，可能偏差 |

## 操作规范

### ✅ 可以做的
- **编辑「总结反馈」列**：输入文字
- **编辑「二次判定」列**：选择 `很好` / `一般` / `淘汰`
- 点进达人链接查看主页内容辅助判断

### ❌ 禁止做的
- **修改任何其他列**（用户名、粉丝数、判定结果、原因等），这些是代码写入的，手动改会导致下次同步冲突或数据不一致
- 删除行
- 修改列名或列类型

---

## 总结反馈 — 填写指南

### 什么时候必须填？

| 二次判定 | 是否必填 | 说明 |
|----------|----------|------|
| `很好` | 可不填 | 代码判定准确，无需补充 |
| `一般` | **必填** | 说明哪里不太合适、为什么不是「很好」 |
| `淘汰` | **必填** | 说明淘汰原因，方便我们优化代码 |

### 反馈应该写什么？

重点是**代码哪里判断得不对或不准确**：

**代码字段不准确的例子：**
- 「粉丝数写 5000，实际看主页有 2 万粉」→ 抓取数据偏差
- 「地区准确性写 是，但这个人明显是土耳其博主」→ 误判
- 「Caption德语占比 80%，但主页内容全是英语」→ 语言检测偏差
- 「判定为复查，原因是无商单，但我看到主页有明确的合作标记」→ 商单检测遗漏
- 「女粉占比无信息，但这明显是个男博主」→ 性别误判

**业务判断的例子：**
- 「内容质量太低，全是转发/搬运」
- 「账号已长期不活跃」
- 「虽符合条件但品类完全不匹配（比如纯B2B账号）」
- 「已联系但拒绝合作」

**写法建议**：简明扼要，一两句话即可。例如：
> 「粉丝数偏差大，实际约 2.5 万。地区判断准确，内容质量可。可联系。」
> 「周三无数据但主页明显是土耳其语+土耳其地址，不应入选。caption 德语占比高是因为偶尔发德语 hashtag。」

> **总结**：二次判断的核心目标是①帮我们找出代码的误判和盲区②确认最终人选。**代码不准确的地方一定要反馈**，这样我们才能持续改进自动化逻辑。
